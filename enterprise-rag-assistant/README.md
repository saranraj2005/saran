# Enterprise RAG Assistant

A document-grounded question-answering app built with Python, Streamlit, LangChain, OpenAI embeddings, and FAISS. Upload PDF documents, index their contents, and ask questions with source references.

## Features

- Upload and process multiple PDF documents
- Split documents into overlapping chunks for retrieval
- Generate semantic embeddings and store them in a local FAISS vector index
- Retrieve relevant passages before generating an answer (Retrieval-Augmented Generation)
- Display source file names and page numbers for retrieved passages
- Keep API credentials in environment variables
- Clear the current session's document index

## Architecture

1. **Ingestion:** Streamlit accepts PDF files and PyPDFLoader extracts their text.
2. **Chunking:** RecursiveCharacterTextSplitter creates overlapping passages.
3. **Embedding:** OpenAI text embeddings convert passages into vectors.
4. **Indexing:** FAISS stores vectors for similarity search.
5. **Retrieval:** The user's question retrieves the most relevant passages.
6. **Generation:** The LLM answers using retrieved context and is instructed to say when the answer is not in the documents.

## Run locally

Requires Python 3.10 or newer.

```bash
git clone https://github.com/saranraj2005/saran.git
cd saran/enterprise-rag-assistant
python -m venv .venv
```

Activate the environment:

- Windows PowerShell: `.venv\Scripts\Activate.ps1`
- macOS/Linux: `source .venv/bin/activate`

Install dependencies and configure the key:

```bash
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and add your OpenAI API key:

```env
OPENAI_API_KEY=your_api_key_here
OPENAI_CHAT_MODEL=gpt-4o-mini
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
```

Start the application:

```bash
streamlit run app.py
```

## Important notes

- This app sends document text and questions to the configured OpenAI API. Do not upload confidential or sensitive documents unless you are authorized to do so.
- API usage may incur charges.
- The app is a portfolio starter, not a production-secured multi-user service. Production deployment should add authentication, persistent storage, access controls, logging, rate limits, and evaluation.
- Answers are generated by an LLM and may be incorrect. Verify important information against the cited source pages.

## Suggested evaluation

Test with a small set of PDFs and record:
- Retrieval relevance (whether the right pages are returned)
- Answer faithfulness (whether claims are supported by retrieved passages)
- Citation correctness (whether source file and page references match)
- Latency and token/API cost per question
